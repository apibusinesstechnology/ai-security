# AI‑Security – Backend

Le backend d’AI‑Security fournit l’infrastructure principale du système : API, logique métier, détection intelligente, communication avec la base de données et intégration des modèles IA.

---

## Fonctionnalités principales

- API REST sécurisée (Express)
- Gestion des utilisateurs et authentification
- Détection de menaces via modèles IA
- Analyse comportementale et scoring de risque
- Journalisation des événements de sécurité
- Intégration avec la plateforme Frontend et Desktop
- Tests automatisés (Jest + Supertest)
